Privacy for Virtual Pet: Cats & Dogs

Scope and developer

This policy describes Virtual Pet: Cats & Dogs version 1.6.0, offered by Sovelivee. Contact website: https://sovelivee.com. It covers the extension, not the separate shopping website or Chrome itself.

What stays on your device

The extension stores your chosen pet name, species, coat, motion and pause settings, interaction count and last action, stars, scores, completed-round count, selected room, tutorial choice and one saved round in chrome.storage.local. Up to 20 completed-round identifiers prevent duplicate rewards. Language choice is stored separately in the same Chrome profile.

Temporary local processing

When you ask to place a pet on a webpage, the extension checks the current tab address to reject unsupported pages. It does not retain or send that address. It processes pointer and keyboard input inside its own controls for play and panel movement. It does not read webpage text, form values or browsing history records.

How data is used

Local data is used to display your pet, save progress, prevent duplicate rewards, apply your language and restore confirmed throws. The extension has no accounts, analytics, advertising, remote AI, cloud sync or network requests. Sovelivee does not receive extension data or sell it. No extension data is shared with advertisers or data brokers.

Backups and imports

Export creates a JSON file on your device. A normal backup includes saved pet data and confirmed throws, including an unfinished round. It excludes unsaved settings, failed throws and language choice. Import reads only the file you choose and asks before replacing saved pet data. Export original data is an inspection copy and cannot be imported as a normal backup. Downloaded files are plain JSON, not an encrypted vault. You control whether to share or delete them.

Retention and deletion

Local data remains in this Chrome profile until you replace or remove it. Reset asks for confirmation, then clears pet and game data while keeping language choice. Import replaces pet data after confirmation. Uninstalling removes the extension’s local data. Downloads are separate files and remain until you delete them. There is no server copy for Sovelivee to retrieve or erase.

Permissions

storage saves local pet data and language. activeTab supplies temporary access after you invoke the extension. scripting inserts the packaged pet panel only when you choose Show on this page. There is no permanent all-sites permission. The extension does not automatically open the developer website.

Browser and website services

Chrome’s installation, update and store systems operate separately from the extension. If you independently visit sovelivee.com, that website’s own privacy practices apply. This policy does not claim the website has no cookies, server logs or analytics.

Hosting of this privacy and help website

This website is hosted by GitHub Pages. GitHub logs visitors’ IP addresses for security purposes. This website hosting is separate from the extension, which does not send your pet data to GitHub or Sovelivee. See the GitHub Privacy Statement for its hosting practices.

Limited use and updates

The extension uses information obtained through Chrome APIs only for the pet features described here and complies with the Chrome Web Store User Data Policy, including its Limited Use requirements. This policy will be updated if those practices change. Policy date: October 19, 2026.

Privacidad de Mascota virtual: perros y gatos

Alcance y desarrollador

Esta política describe la versión 1.6.0 de Virtual Pet: Cats & Dogs, ofrecida por Sovelivee. Sitio de contacto: https://sovelivee.com. Se aplica a la extensión, no a la tienda web ni a Chrome.

Datos en tu dispositivo

La extensión guarda el nombre, la especie, el pelaje, los ajustes de movimiento y pausa, las interacciones y la última acción, las estrellas, los récords, las partidas completadas, la habitación, la elección del tutorial y una partida en chrome.storage.local. Conserva hasta 20 identificadores de partidas completadas para evitar recompensas duplicadas. El idioma se guarda por separado en el mismo perfil.

Procesamiento temporal

Al pedir una mascota en una página, se comprueba la dirección de la pestaña actual para evitar páginas no compatibles. No se conserva ni se envía. Los movimientos del puntero y las teclas dentro de sus propios controles permiten jugar y mover el panel. La extensión no lee texto de páginas, valores de formularios ni registros del historial.

Uso de los datos

Los datos locales sirven para mostrar la mascota, guardar el progreso, evitar premios duplicados, aplicar el idioma y recuperar lanzamientos confirmados. No hay cuentas, analítica, publicidad, IA remota, sincronización en la nube ni solicitudes de red. Sovelivee no recibe ni vende los datos de la extensión. No se comparten con anunciantes ni intermediarios de datos.

Copias e importaciones

Exportar crea un JSON local. Una copia normal contiene la mascota y los lanzamientos confirmados, incluso de una partida incompleta. No incluye ajustes sin guardar, lanzamientos que no se guardaron ni el idioma. Importar lee solo el archivo elegido y pide confirmación antes de reemplazar los datos. La exportación de datos originales sirve para inspección y no se importa como copia normal. Los archivos son JSON sin cifrar, no una caja fuerte. Tú decides si compartirlos o borrarlos.

Conservación y eliminación

Los datos permanecen en este perfil hasta que los reemplazas o eliminas. Restablecer pide confirmación, borra mascota y progreso, y conserva el idioma. Importar reemplaza los datos de la mascota tras confirmarlo. Desinstalar elimina los datos locales de la extensión. Los archivos descargados permanecen hasta que los borras. Sovelivee no tiene una copia en un servidor que pueda recuperar o eliminar.

Permisos

storage guarda datos e idioma. activeTab da acceso temporal al invocar la extensión. scripting inserta el panel incluido solo al elegir Mostrar en esta página. No hay permiso permanente para todos los sitios. La extensión no abre automáticamente la web del desarrollador.

Chrome y el sitio web

La instalación, las actualizaciones y la tienda de Chrome funcionan por separado. Si visitas sovelivee.com por tu cuenta, se aplican las prácticas de privacidad de ese sitio. Esta política no afirma que el sitio carezca de cookies, registros de servidor o analítica.

Alojamiento de este sitio de privacidad y ayuda

Este sitio está alojado en GitHub Pages. GitHub registra las direcciones IP de sus visitantes por motivos de seguridad. El alojamiento de este sitio es independiente de la extensión, que no envía los datos de tu mascota a GitHub ni a Sovelivee. Consulta la Declaración de privacidad de GitHub para conocer sus prácticas.

Uso limitado y cambios

La información obtenida mediante las API de Chrome se usa solo para las funciones de la mascota descritas aquí, de acuerdo con la Política de Datos de Usuario de Chrome Web Store y sus requisitos de Uso Limitado. Actualizaremos esta política si cambian esas prácticas. Fecha: 19 de octubre de 2026.

Virtual Pet：猫与狗隐私政策

范围与开发者

本政策说明Sovelivee提供的Virtual Pet: Cats & Dogs 1.6.0。联系网站：https://sovelivee.com。适用范围是插件，不是独立的购物网站或Chrome本身。

保存在设备上的资料

插件将宠物名、物种、毛色、运动和暂停设置、互动次数及最后动作、星星、成绩、完成局数、房间、教程选择和一局游戏保存到chrome.storage.local。最多保留20个已完成回合标识用于防止重复奖励。语言偏好单独保存在同一Chrome用户配置中。

临时本地处理

当你要求在网页显示宠物时，程序检查当前标签地址以排除不支持的页面，不保留或发送该地址。它只在自身控件内处理用于游戏和移动面板的鼠标、触摸或键盘输入，不读取网页正文、表单值或浏览历史记录。

资料用途

本地资料用于展示宠物、保存进度、防止重复奖励、应用语言和恢复已确认投球。插件没有账号、分析追踪、广告、远程AI、云同步或网络请求。Sovelivee不接收或出售插件数据，也不向广告商或数据经纪商分享插件数据。

备份与导入

导出会在你的设备上生成JSON文件。正常备份包含已保存宠物及已确认的投球，包括未完局；不含未保存设置、保存失败的球或语言。导入仅读取你主动选择的文件，替换宠物前会确认。原始数据副本仅供检查，不能作为普通备份导入。下载文件是未加密JSON，不是加密保险箱，由你决定是否分享或删除。

保留与删除

资料保留在当前Chrome用户配置，直到你替换或删除。重置确认后清除宠物和游戏资料，但保留语言；导入确认后替换宠物资料。卸载移除扩展本地数据，下载的文件需自行删除。Sovelivee没有可供找回或代删的服务器副本。

权限

storage保存本地宠物和语言。activeTab在调用扩展后提供临时访问；scripting只在点击“显示在此网页”后注入包内面板。没有永久全站权限，也不会自动打开开发者网站。

浏览器与网站

Chrome的安装、更新和商城服务独立于插件。如果你自行访问sovelivee.com，则适用该网站的隐私规则。本政策不声称官网没有Cookie、服务器日志或分析服务。

隐私与帮助网站的托管

此网站由GitHub Pages托管。GitHub会出于安全目的记录访问者的IP地址。这是访问网页时的托管行为，与插件本身分开；插件不会向GitHub或Sovelivee发送宠物资料。托管服务的数据处理详见GitHub隐私声明。

有限用途及更新

通过Chrome API获得的信息只用于这里说明的宠物功能，遵守Chrome Web Store用户数据政策及有限用途要求。如处理方式改变，将更新本政策。政策日期：2026年10月19日。
