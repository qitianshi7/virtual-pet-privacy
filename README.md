# Virtual Pet privacy and help

Public privacy policy and help for Virtual Pet: Cats & Dogs 1.6.0, offered by Sovelivee.

- `privacy.html`: English (US), Spanish and Simplified Chinese privacy policy.
- `support.html`: help in the same three languages.
- `index.html`: project information and links to the policy and help.
- `site.css`: local styles; no third-party scripts or fonts.

Contact website: https://sovelivee.com

The extension works locally. Hosting these public documents does not add networking, telemetry or cloud storage to the extension. The privacy policy separately explains GitHub Pages hosting logs.

Publish using GitHub Pages from the main branch, repository root. Keep these documents aligned with the extension whenever its data handling changes.
